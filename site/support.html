Installation

SelectPilot requires Chrome, the SelectPilot local helper, and Ollama. The extension checks each part and recommends an efficient model for your hardware.

If setup takes longer

Keep the installation window open. Model downloads vary with connection speed and available local storage. SelectPilot will explain only when an action is required.

If processing is unavailable

Open SelectPilot and use Re-check. If Ollama is stopped, start it and try again. SelectPilot will not silently send work to a cloud model.

Contact

Email support@selectpilot.app. Include your operating system and the exact message shown, but never include selected private text or your license key.
